# Local Legacy Icon Builder

This folder contains a local-only browser tool for designing UniPatches overlay icons.

## Run it

From the repository root:

```bash
python3 -m http.server 4173 --directory tools/icon-builder
```

Open `http://localhost:4173` in a browser. The tool does not send icon rows, images, or settings anywhere.

## What it supports

- Multi-part icon rows using the runtime-compatible pipe-separated format.
- All runtime shapes, including `roundedTriangle` and `ring`.
- Position, dimensions, rotation, fill, colors, stroke, opacity, layer, text, bold text, and per-part font choices.
- Eight font choices: Default (Android), Roboto, Sans serif, Serif, Monospace, Sans condensed, Sans medium, and Sans black.
- Legacy text/shape mode with shape gradient, shape scale, stroke, background, outline, highlight, size, opacity, position, and button shape controls.
- Local image preview without uploading the image.
- Built-in starting templates for common icon styles.
- Import from a `.txt` row list, complete editor JSON, or dedicated legacy icon JSON.
- Copy rows and download `.txt`, complete editor JSON, or dedicated legacy icon JSON.

The raw row editor accepts one part per line:

```text
shape|position-x|position-y|scale-w|scale-h|rotation|fill|color1|color2|stroke|opacity|layer|text|bold|font
```

The generated `iconParts` rows can be pasted directly into the Universal Overlay multi-part icon setting. Dedicated legacy icon JSON exports can be imported into the patch option of the same name; they take priority over legacy text/shape settings and multipart rows, below a valid custom image. `patches-list.json` is intentionally not generated by this tool; semantic workflow owns that artifact.
